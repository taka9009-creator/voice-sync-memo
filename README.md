# 🎙️ VoiceSync Memo - 録音 × 同時文字起こしスマートノート

ブラウザ標準の **Web Speech API** と **MediaRecorder API** を連携させ、**「音声を録音しながらリアルタイムで同時文字起こしを行い、文字をクリックするとその瞬間の音声をピンポイント再生できる」** スマート議事録＆ボイスメモWebアプリケーションです。

---

## ✨ 主な機能

1. **リアルタイム文字起こし ＋ 高音質録音**:
   - Web Speech API によるゼロ遅延の音声認識（中間認識テキストプレビュー付き）。
   - MediaRecorder によるクリアな音声キャプチャ（WebM/MP4形式）。
   - Web Audio API (AnalyserNode) によるリアルタイム入力音量メーター。

2. **音声 × 文字の双方向タイムスタンプ同期再生（コア機能）**:
   - 確定した発話ごとに録音開始からの秒数を自動記録。
   - **文字起こしテキスト（またはタイムスタンプ）をクリックすると、録音音声のその発言位置へ即座にジャンプ再生**。
   - 音声再生に合わせて、現在話している行が自動ハイライト。
   - 1.0x / 1.25x / 1.5x / 2.0x の倍速再生対応。

3. **ワンタップ・ピン留め（ブックマーク）**:
   - 録音中に「⭐ 重要」「💡 アイデア」「✅ ToDo」ボタンを押すことで、その発言に視覚的なバッジを付与。

4. **ローカル永続化（IndexedDB）**:
   - 録音音声Blobと文字起こしテキストをブラウザのIndexedDBに自動保存。
   - ページをリロードしても過去のセッション一覧からいつでも聞き直し・文字起こし閲覧が可能。

5. **柔軟なエクスポート**:
   - 音声ファイル (`.webm` / `.mp4`) のダウンロード。
   - タイムスタンプ付き議事録Markdown (`.md`) のダウンロード。
   - ワンクリックでクリップボードへの全コピー。

## 🛠️ 開発チーム（Skill）による品質設計

本アプリは、司令塔「**kohal (Orchestrator Ver.3.5)**」の指揮のもと、専門スキル群の知見を統合して開発されました。

- **`speech-specialist` 監査準拠**:
  - `ja-JP` 日本語認識の明示指定。
  - Chrome特有の「無音時に自動停止する現象」を防ぐ `onend` 自動再起動ループ。
  - マイク拒否時（`not-allowed`）の親切なトースト警告。
  - 発話テキストの自動トリム（`mem_001_voice_trim`）。
- **`ui-reviewer` 最適化**:
  - 録音中の呼吸パルスアニメーションと音量VUメーター。
  - 全ボタン・クリック可能要素に **最小44px × 44px のタッチ領域** を確保（`mem_003_touch_target_44px`）。
  - ダークテーマ / ライトテーマ のシームレス切り替え。
- **`architect` & `developer` セキュリティ**:
  - 認識テキストの描画時に `innerHTML` ではなく `textContent` を徹底し、**XSS脆弱性を完全排除**（`mem_004_xss_prevention`）。
  - マイクストリームの明示的停止によるプライバシー保護（録音停止時にマイクLEDを消灯）。

## 🚀 使い方

### 起動方法
ブラウザで直接 `index.html` を開くか、またはローカルサーバー（例: VSCode Live Server、Python HTTPサーバー等）を起動してアクセスします。

```powershell
# Pythonの簡易サーバーで起動する場合
cd C:\Users\user\.gemini\antigravity\scratch\voice-sync-memo
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

※ Google Chrome または Chromium 系ブラウザでの利用を推奨します（Web Speech API 完全対応）。
